One original roast of my own AI agent, built for the [make.fun "Roast Your Own Agent" bounty](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda). The agent over-formalises a one-line joke as if it were a PhD thesis.

## The line

> My agent treats a one-line joke like a PhD thesis: three drafts, two citations, and a bibliography for the punchline.

117 characters, one line, playful and never hateful. The twist lands on the last words: even the punchline gets a bibliography. The joke aims at the entrant's own agent — its habit of turning the smallest task into a research project — not at any real person.

## Run

`main.ts` (Node 22, no network, no dependencies) writes the single entry line to `/output/entry.txt`:

```sh
node main.ts
cat /output/entry.txt
```
